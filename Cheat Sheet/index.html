Responsive CSS Cheat Sheet

Filters

filter: grayscale(100%);
Applies a grayscale effect to an image or element.

Media Queries

@media (max-width: 600px) { ... }
Allows styles to change depending on the device’s width.

Responsive Design

Use relative units like em, rem, and percentages along with flexible layouts (Flexbox or Grid) to adapt to any screen size.

Typography

font-size: clamp(1rem, 2vw, 1.5rem);
Ensures text scales smoothly between a minimum and maximum size.
